# Automatización de separación y columnado para informes Visa y MasterCard

Este proyecto proporciona un script diseñado para automatizar el proceso de separación y columnado de los archivos **DEBLICQ** y **DEBLIMC**, utilizados en la generación de informes para **Visa** y **MasterCard**.

## Funcionalidad
El script permite cargar los archivos de respuesta provenientes de **Prisma**, procesarlos y obtener como resultado los informes ya separados, ordenados y columnados para su uso inmediato.

## Requisitos previos
- Contar con los archivos de respuesta suministrados por **Prisma**.
- Un navegador web para visualizar el HTML.
- (Opcional) Una herramienta para servir el proyecto localmente, como Live Server.

## Instrucciones de uso
1. Clonar este repositorio en tu máquina local.
   ```bash
   git clone https://github.com/MauriBarrientos/script-visa-mc-automatization.git

2. Abrir el archivo HTML en tu navegador.
   Puede hacerse directamente o usando herramientas como Live Server.

3. Cargar los archivos DEBLICQ y/o DEBLIMC provenientes de Prisma en la interfaz del script.

4. Descargar el informe procesado, ya separado y columnado automáticamente
